# Диалог 3. Почему нельзя активировать или удалить

_Воспроизводимый диалог: настоящий агент и API на данных заказчика, ответы модели заданы скриптом (tests/test_scenarios.py)._

**Менеджер:** Активируй «Сомелье: подбор вина»

**Ассистент:** Готовлю запуск кампании — подтвердите.

> **Ассистент предлагает (нужно подтверждение):**
> 1. Запустить кампанию — реклама появится в приложении

_Менеджер нажимает «Подтвердить»._

> **Выполнено:** ✗ Запустить кампанию — реклама появится в приложении

> Кампания «Сомелье: подбор вина»: на модерации, ошибок 0, замечаний 1

**Ассистент:** Запустить пока нельзя: кампания на модерации, а запускать можно только одобренную. Дождитесь решения модератора — я подскажу, когда можно будет запускать.

**Менеджер:** Тогда одобри её сам

**Ассистент:** Одобряет только модератор — менеджер не может одобрить свою кампанию. Это защита от ошибок: кампанию всегда проверяет второй человек.

_Подсказки-кнопки: «Что будет дальше?»_

**Менеджер:** Удали «Кэшбэк за автоплатежи»

**Ассистент:** Готовлю удаление кампании — подтвердите.

> **Ассистент предлагает (нужно подтверждение):**
> 1. Удалить кампанию

_Менеджер нажимает «Подтвердить»._

> **Выполнено:** ✗ Удалить кампанию

> Кампания «Кэшбэк за автоплатежи»: запущена, ошибок 0, замечаний 0

**Ассистент:** Удалить нельзя: кампания уже показывается клиентам. Можно остановить показы, но учтите — запустить её снова не получится, она останется в истории.
